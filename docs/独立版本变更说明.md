# 独立版本变更说明

本次调整使平台当前业务独立于旧系统。当前验收结果以[test-reports/standalone-summary.json](test-reports/standalone-summary.json)为准，既有分阶段设计和执行记录属于历史过程资料。

## 已移除的业务功能

- “我的线索”中的“旧版历史档案”板块及组件。
- 管理端的历史档案文件上传、预演、账号映射和导入入口；菜单改为“账户管理”。
- 后端档案服务与控制器；`/api/v1/legacy-reports`、`/api/v1/migration/preview`、`/api/v1/migration/import`不再注册。
- 原数据导出及旧账号准备工具。当前运行、测试、浏览器验收和重启验收均不再要求旧数据或旧账号映射文件。

## 当前业务保持的规则

线索上传、模型风险检测、初审/独立复核、预算奖励、模拟提现、通知、角色和区域授权继续使用当前平台的数据与接口。普通线索列表中的证据入口仅向上传者显示；审核人员从审核工作台按权限查看证据，避免误用仅限本人访问的图片接口。

## 数据库版本

Flyway已执行的版本脚本及校验和保持不变，包括V8中历史上创建的档案表。现有档案表不再有业务接口或页面，保留在数据库中，不在本次页面和功能删除操作中清空数据。新部署也不需要导入任何旧系统数据。

## 验证方式

完整Java集成回归和Python协议测试；真实浏览器走上传、原模型检测、独立复核、奖励及模拟提现链路；检查档案板块和导入入口消失，并以普通账号及管理员身份验证移除接口返回404；核对运行Jar、前端构建摘要与测试产物一致，重启后就绪与维护任务恢复，对账差异为0。

此前修复的XXL-JOB网页登录密码长度规则一并保留：调度管理员密码为20位随机Base64url，其余服务独立长密钥不变，部署关卡验证实际登录表单限制与后台访问。
