# 接口迁移清单

新 API 前缀 `/api/v1`，新数据库 `traffic_platform`。P8新Vue入口及独立演示部署已完成切换；旧入口/旧库仍保留，历史数据通过显式归档导入，不将其伪装成当前已结算订单。

| 原能力 | 新能力 | 必要变化 | 当前状态 |
| --- | --- | --- | --- |
| /login、Sa-Token 登录 | /auth/login、/auth/refresh、/auth/logout、/auth/me | JWT/Redis/BCrypt，前端token契约同步调整 | P2/P8通过；新入口不读取spba旧会话 |
| /admin、/roles、/menus | /identity/users、roles、regions、catalog；权限驱动菜单 | 受控创建/授权/重置密码，权限变更撤销旧凭据 | P8账户页面及权限隔离通过 |
| 违章类型字典 | 征集任务与公布规则 | 发布窗口、预算、规则快照；按新需求以征集规则替代旧类型字典 | P3/P8通过；未继续复制旧字典CRUD |
| /user/report | /reports、/evidence | 任务归属、幂等键、独立检测状态、受控二进制读取 | 新入口提交与实际模型链路P8通过 |
| 定时扫描 reports.status=0 | detection_task + Outbox + RabbitMQ | 事务外推理、租约、失败隔离、XXL恢复 | P4/P7/P8通过真实MQ、权重和模型重启验证 |
| /inspector/report/status/{id} | /review-tasks/{id}/decisions | 区域/分配归属、版本、独立复核、申诉 | P5/P8通过，页面实际领取/看图/复核 |
| 审核直接加余额 | reward_order + wallet_entry | 同事务预算预留、唯一业务号、幂等入账、补偿流水 | P6/P8通过，实际入账与对账差异0 |
| /user/withdrawals、/admin/withdrawals | /withdrawals、/management/withdrawals | 金额/身份/区域验证；模拟冻结与审批，不采集真实收款账号 | P6/P8通过，禁止自审批 |
| ECharts聚合与操作日志 | /operations/summary、审核/授权审计、/notifications | 维护与积压指标无个人详情，业务数据保持区域/归属授权 | P7/P8通过，真实XXL与通知已验收 |
| 旧账号与reports | /migration/preview、/migration/import、/legacy-reports | 先只读导出、预演，再显式新账号映射与归档；不导入密码/权限/旧资金 | P8核对11账号/44线索，重复导入幂等、停用状态不变 |

旧状态仅作为迁移输入：0 未检测、1 模型判为 AI、2 待审核、3 审核有效、4 审核无效。新系统不会把旧 status=1 直接当成“已确认造假”，需保留来源并进入复核/历史待确认映射。
