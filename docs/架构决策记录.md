# 重构架构决策

## ADR-001 并行迁移

旧后端存在用户未提交变更；新后端建在 `traffic-platform`，不通过复制全部旧配置/依赖启动。旧服务不停止，原数据库不修改；新数据库名称和容器资源独立。最终前端切换前不宣称迁移完成。

## ADR-002 构建基线

Java 21（本机 21.0.6），Spring Boot 4.1.2。该版本于 2026-11-03 从官方系统要求页和 Aliyun Maven metadata 双重核对。Spring 相关版本优先由 BOM 管理。旧 MyBatis-Plus starter 替换为 Boot 4 专用 starter，具体版本在引入阶段验证。

构建使用 `traffic-platform/tools/build.ps1`，显式调用 JDK 21 与 Maven launcher，不修改系统 JAVA_HOME。缓存位于工作区 `.cache/maven`；settings 中 file 仓库只读取本机旧依赖，再从远程镜像补齐。换机可传 JDK/Maven 路径并移除本机缓存仓库配置。

## ADR-003 阶段证据分层

P1 使用 H2 证明骨架与迁移脚本能运行；P2 必须运行隔离 MySQL、Redis。Mock/H2 不能替代 P2 真实基础设施检查。P4 必须运行真实 RabbitMQ。任何 skipped 项不能把关卡标为通过。

## ADR-004 鉴权契约

新端点采用 `/api/v1`；Bearer JWT、HTTP 401/403 与统一错误结构。JWT 验证签名、issuer、audience 和时效；Redis 会话作为注销/停用的撤销依据。刷新令牌仅保存哈希并原子轮换。旧前端 satoken/code=501 在 P8 显式切换。

## ADR-005 风险与审核分离

AI 分数是风险信号，不是违章判定或用户造假证据。检测、审核、奖励三个状态维度独立。检测高风险进入复核，不自动处罚。奖励与审核版本关联，旧事件不覆盖新决议。

## ADR-006 一致性

MySQL 约束最终保护账务与预算；MQ 至少一次，消费者幂等。线索与 Outbox 同事务；预算预留与奖励订单同事务；余额、流水、奖励完成同事务。外部模型和消息投递不占用数据库长事务。任务租约与 attempt token 防止过期执行结果覆盖。
